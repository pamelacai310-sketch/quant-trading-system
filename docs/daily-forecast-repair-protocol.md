# 单日期货预测修正协议

本协议于2026-09-08复盘后制定。9月8日结果已知，任何重算只能称为事后诊断，不能称为新的盲测或真实盘前预测。

修正目标是阻止未经验证的方向值被作为可用预测发布，同时检验加入同行市场状态能否改善价格模型。不降低原生因果引擎的准入要求，不把弃权当作预测正确。

## 固定实验

- 比较三种方法：价格不变；原7特征岭回归；7特征加市场/产业组状态岭回归。
- 两个回归均使用最近120个完整、严格相邻交易日标签，最少60个，岭惩罚10，训练窗口标准化并截断到±5，输出向0收缩50%。参数沿用原实验，不进行超参数搜索。
- 新特征只取预测时点已知的同行1日收益、5日平均收益、上涨比例、当日横截面波动。产业组和市场组均排除目标合约；商品与金融合约分组；最少3个产业组同行、10个市场同行，不用缺失值填0。
- 精确合约日线必须以显式交易日历对齐。缺日、零成交和无效OHLC不插值，不能拼成虚假“下一交易日”。
- 前段诊断截至2026-08-07；2026-08-10至2026-09-07留作后段诊断，9月8日单列。所有参数固定，不依据后段结果再调整。由于设计者已看过原结果，两段都不声称是未触碰过的盲测。
- 所有历史预测按时间重新训练。某日的发布门槛只使用该日收盘已经兑现的此前预测结果，9月8日结果绝不能进入9月7日门槛。

## 发布门槛

每个候选/合约需要至少60个不同目标交易日的历史样本外预测。按5个连续可用目标日的块汇总“基准绝对误差−模型绝对误差”和方向命中超额，构造正态近似95%单侧下界，并对两个候选作Bonferroni修正。两项下界都必须大于0，且新旧两个半段的平均误差改进均为正。因块间仍可能相关且存在多合约、重复评估，此值只是历史筛选诊断，不能当作严格全流程显著性检验、收益保证或独立前瞻验证。

真实前瞻验证日期必须由未来实验填入。当前所有回放都标为retrospective；缺少前瞻证据时只输出research_only/abstain，发布预测字段为null，另列价格不变参考值。零值不能冒充方向预测，弃权不能计为胜率。

## 区间与评价

使用先前样本外绝对残差除以当时20交易日波动率，至少30个校准误差。按ceil((n+1)*0.8)阶统计量生成对称范围，再乘最新已知波动率。研究回放可围绕候选点计算诊断区间；正式输出只有当研究点被批准时才能以它为中心。弃权时如需输出参考范围，必须使用围绕价格不变校准的reference_radius，并明确标为参考。时间依赖下不保证80%覆盖，始终报告实际覆盖率。

按目标交易日汇总同日合约误差，避免把同日几十个相关合约当独立交易日。同时报告覆盖率、弃权率、MAE、零变化基准MAE、方向命中、原始/收缩估计和不同阶段结果。平盘计入方向未命中；无方向预测不计方向分母。

## 可解决范围

本次可以修复：单日目标、时间对齐、缺失处理、证据门槛、区间口径、错误胜率统计和可复现记录。未来价格无法保证；新增市场状态是否有预测力必须以实验为准。新闻、库存、持仓结构、海外数据未有带可用时间的数值输入时明确记为缺失，不用叙事补造系数。

## 使用入口

原生引擎现在提供run_daily_research(symbol_datasets, trading_calendar, asof)，明确标注目标为1个交易日、收盘到收盘收益、retrospective和forward_validated=false，返回研究诊断及弃权记录。原run_learning_cycle的5行观测目标未被改成单日预测，原筛选门槛也未改变。

命令行：python -m quant_trade_system.daily_forecast --input manifest.json --asof 2026-09-07 --output new_replay.json。manifest包含calendar日期数组及contracts对象（精确合约到OHLCV行列表）。输出必须为新文件，避免覆盖既有预测。回放文件中的candidate_point是诊断值；消费端必须使用publication中的prediction_close_return，并处理null为“无有效预测”。

复现本次实验：python scripts/audit_daily_forecast_repair.py --workspace /path/to/quant_workspace --output /path/to/new_audit。工作区需保留analysis-20260908和actual-validation-20260908的冻结证据。研究池为原67个有数值条目，包含用户新增品种中的纯苯、丙烯、铂、钯；原木无12月合约，不进行伪造补值。

前瞻升级需要后续真实日期形成的不可覆盖预测快照、当时输入哈希与出具时间、次日收盘后记录的实际结果，以及按日期隔离的评价。当前入口不会仅凭历史门槛解锁正式发布，更不会发出交易指令。
