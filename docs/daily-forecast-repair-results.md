# 2026-09-08预测失误修正实验

本次设计发生在9月8日结果已知之后，全部结论是历史诊断。实验规则见[daily-forecast-repair-protocol.md](daily-forecast-repair-protocol.md)。

## 问题与实现

原生引擎67个具体合约有66个未通过特征筛选、1个历史不足，没有已通过筛选的方向信号。原表58个非基准数值来自额外的7特征岭回归；其9月8日方向命中24/58（41.38%），MAE 1.454个百分点，差于价格不变的1.403个百分点。模型平均预测−0.0449%，实际平均+1.3215%。

新增独立的一交易日研究入口，明确收盘到收盘目标。日历来自交易所休市通知，缺日、零成交和无效OHLC不能拼成单日标签。校准和历史准入只使用当时已兑现的数据。回放没有真实前瞻证据，正式预测字段为空，价格不变单列参考，不能把弃权计为预测成功。

## 实验结果

两个回归使用相同固定参数。加入市场和产业组特征后，在8月10日至9月7日的同一823个合约日上，MAE由1.164变为1.167个百分点，价格不变为1.153个百分点。在9月8日同一41个合约上，新候选幅度误差略小，但仍差于价格不变。没有采用新候选作为正式预测。

对原7特征模型按相同样本校准区间：此前21日的935个样本，覆盖率76.26%→78.40%，平均全宽3.464→3.791个百分点；9月8日48个样本，覆盖率64.58%→70.83%，平均全宽3.373→3.726个百分点。改善来自更合适且更宽的范围，方向准确率没有因此提高，也不保证未来80%覆盖。

补齐旧日历遗漏的2025年1月9日和1月24日后，58个原方向预测在1e−10收益率容差内全部复现。日历是应修复的数据隐患，但不是该日预测失误的主要原因。

## 验证与限制

9项新增测试及18项原生引擎回归测试通过。固定67个合约池有后选样本限制，同日合约并非独立样本；没有证明真实前瞻预测优势或扣费后盈利。新闻与夜盘缺少当时可用的量化输入时不补造，OpenClaw晨报正文缺失不等同于有效学习证据。

本次只交付本地研究入口与验证，不自动修改OpenClaw任务或生产交易入口。后续升级仍需要真实时间产生的不可覆盖预测、输入和结果记录；历史筛选本身不会解锁发布。

复现脚本会生成summary.json、root_cause_evidence.json、all_walk_forward_records.json、event_comparison.csv和retrospective_publication.json，并记录冻结输入的SHA-256。发布覆盖率为0，准确率不适用。
