# 周波段T0-T5短线策略指南

## 📊 策略概述

周波段T0-T5短线策略是一种**快速周转、不过周末**的短线交易策略，核心特点：

1. **持仓周期T0-T5**：从买入日（T0）到第5天（T5）或周五前必须平仓
2. **长期看好标的反复波段**：在每周相对低位接回，持续做T+0到T+5的波段
3. **每周收益目标2万**：本金100万，目标每周净赚2万（2%收益率）

---

## 🎯 策略参数

### 基础参数

| 参数 | 默认值 | 说明 |
|------|--------|------|
| 初始资金 | 1,000,000港币 | 本金100万 |
| 每周目标 | 20,000港币 | 目标净赚2万 |
| 目标收益率 | 2% | 每周2% |
| 最大持仓 | 5只 | 同时持仓不超过5只 |
| 最大天数 | 5天 | T0-T5，最晚周五平仓 |
| 止损幅度 | 3% | 硬止损 |
| 止盈幅度 | 6% | 目标止盈 |

### 持仓周期规则

```
周一(T0) → 周二(T1) → 周三(T2) → 周四(T3) → 周五(T4) → 必须平仓
```

**关键规则**：
- ✅ T0买入，T0-T5任意时间卖出
- ✅ 最晚周五下午3点前必须平仓
- ❌ 严禁持仓过周末
- ❌ 严禁在周五晚开新仓

## 💡 核心逻辑

### 1. 时间周期管理

**为什么T0-T5？**
- 短期波动难以预测，5天是合理的持有周期
- 避免周末的不确定性（财报、政策、黑天鹅）
- 快速周转，提高资金使用效率

**周五必须平仓的原因**：
- 周末可能发生重大事件
- 避免隔夜风险累积
- 保持资金灵活

### 2. 长期看好标的反复波段

**哪些是长期看好的标的？**
- 大盘科技股：AAPL、MSFT、GOOGL、TSLA、NVDA
- 港股科技：0700.HK（腾讯）、9988.HK（阿里）、3690.HK（美团）
- 期货主力合约：ES、NQ、CL、GC

**波段操作流程**：
```
第1周: 周一低位买入 → 周四高位卖出 → 盈利5%
第2周: 周二回调买入 → 周五止盈 → 盈利4%
第3周: 周一急跌买入 → 周三反弹卖出 → 盈利6%
...持续循环
```

**核心思想**：不追求一次性抓住全部涨幅，而是每周吃一小段利润

### 3. 每周2万目标的实现路径

**目标分解**：
- 每周目标：20,000港币
- 单笔盈利目标：4,000港币（5笔）
- 单笔收益率：5%
- 单笔投入：80,000港币

**达成路径**：
```
假设平均每笔盈利5%：
需要盈利笔数 = 20,000 / (80,000 × 5%) = 5笔

如果胜率80%：
- 5笔盈利 × 5% = +20,000
- 1笔止损 × 3% = -2,400
- 净利润 = +17,600
```

**关键**：高胜率 + 严格止损 = 稳定盈利

## 📈 选股标准

### 股票选择

**核心标准**：
1. **高波动率**：日均波动 > 3%
2. **高流动性**：日成交额 > 1亿
3. **趋势明确**：处于上升趋势或震荡上行
4. **催化剂**：有业绩、政策、题材支撑

**技术信号**：
- 突破关键均线（MA5、MA10）
- RSI在30-70区间（超卖回升或强势区）
- 成交量放大（确认突破）

**排除标准**：
- 即将发布财报（不确定性大）
- 前期暴涨（回调风险高）
- 流动性差（小盘股、仙股）

### 期货合约选择

**适合的期货品种**：
- **股指期货**：ES（标普500）、NQ（纳斯达克）
- **商品期货**：CL（原油）、GC（黄金）、SI（白银）
- **国内期货**：RB（螺纹钢）、CU（铜）

**期货优势**：
- T+0交易，可当日平仓
- 双向交易，可做多可做空
- 高杠杆，资金效率高
- 流动性极好

**期货风险**：
- 杠杆高，止损必须严格
- 波动大，需要快速反应
- 手续费成本

## 🕐 交易时间表

### 周一（T0）

**9:30 开盘**
- 观察市场整体走势
- 寻找开盘急跌的机会（建仓良机）
- 检查长期看好标的是否回调

**10:00-11:30**
- 扫描符合条件的标的
- 分批建仓（最多2只）
- 设置止损单

**14:00-15:00**
- 评估持仓表现
- 考虑是否加仓
- 准备尾盘调仓

### 周二-周四（T1-T3）

**每日操作**：
- 检查止损止盈
- 部分止盈（如果达到+5%）
- 继续持有优质仓位
- 扫描新的机会

**最佳平仓时机**：
- T1-T2：快速止盈（+5%到+8%）
- T3：考虑是否延长到T4

### 周五（T4/T5）

**上午**：
- 最后的交易机会
- 不建议开新仓（除非极好机会）

**14:00**：
- 开始准备平仓
- 评估所有持仓

**15:00前**：
- **所有持仓必须平仓**
- 不持过周末

**15:30**：
- 总结本周交易
- 计算盈亏
- 计划下周操作

## ⚠️ 风险管理

### 仓位管理

**单笔风险控制**：
- 单笔最大风险：2%（20,000港币）
- 止损幅度：3%
- 单笔投入：约666,666港币

**仓位分配**：
- 每只股票：20%仓位
- 同时持仓：最多5只（100%仓位）
- 剩余现金：应对追加保证金（期货）

### 止损止盈

**止损纪律**：
- 硬止损：-3%无条件止损
- 时间止损：T5必须平仓
- 周五止损：下午3点前必须平仓

**止盈策略**：
- 分批止盈：
  - 第一批：+5%平仓50%
  - 第二批：+8%平仓剩余50%
- 快速止盈：如果快速+6%，全部平仓
- 保护利润：浮盈+4%后，跟踪止损调整为+2%

### 止损案例

**场景1：触发止损**
```
T0买入 @ $100
T1价格 $97（-3%）
→ 触发止损，平仓亏损$3
```

**场景2：时间止损**
```
T0买入 @ $100
T4价格 $98（-2%）
→ 虽未触发止损，但接近周五，提前平仓
```

**场景3：止盈**
```
T0买入 @ $100
T2价格 $106（+6%）
→ 触发止盈，平仓盈利$6
```

**第1周**：

- 周五涨至$390，必须平仓

**第3周**：
- 周一高开$395，观望不追
- 周三回调至$380，买入

**第4周**：
- 本周震荡，无好的买点
- 空仓休息
- 盈利：$0

**4周总结**：
- 总盈利：$42,000
- 周均盈利：$14,000（目标达成率70%）
- 胜率：75%（3胜1负0空仓）

### 案例2：特斯拉（TSLA）T0-T1快速止盈

**交易过程**：
- T0（周二）：特斯拉财报后急跌至$180，买入500股
- T1（周三）：快速反弹至$189
- 决策：触发+5%止盈，全部卖出
- 盈利：$4,500（5.00%）

**关键点**：
- 快速止盈，不贪心
- 避免持过周末
- 继续等待下周机会

### 案例3：原油期货（CL）双向交易

**做多交易**：
- T0（周一）：原油跌至$75，做多5手
- T2（周三）：涨至$78，止盈
- 盈利：$(78-75) × 1000 × 5 = $15,000

**做空交易**：
- T0（周三）：原油涨至$82，做空5手
- T1（周四）：跌至$79，止盈
- 盈利：$(82-79) × 1000 × 5 = $15,000

**两周盈利**：$30,000（超额达成目标）

## 💪 实战技巧

### 选股技巧

1. **周一开盘急跌是黄金坑**
   - 很多时候是周末消息面造成的恐慌
   - 如果是优质股，急跌是建仓良机

2. **优先选择长期看好的标的**
   - 熟悉的标的更容易把握波动规律
   - 可以反复做波段

3. **避开财报期**
   - 财报前1周不开仓
   - 财报后等待方向明确再入场

4. **关注成交量**
   - 放量突破更可靠
   - 缩量回调是机会

### 择时技巧

1. **T0-T2是黄金期**
   - 前3天盈利概率最高
   - 快速止盈，不恋战

2. **T3-T4谨慎**
   - 持仓超过3天要注意
   - 考虑是否提前平仓

3. **周五下午必须平仓**
   - 不抱侥幸心理
   - 周末风险不可控

### 心态管理

1. **接受止损**
   - 每周会有1-2笔止损是正常的
   - 止损是为了保护本金

2. **达成目标后休息**
   - 周二就达成2万目标？可以休息
   - 不为了交易而交易

3. **未达成不要追**
   - 周四只赚了1万？不要加大仓位追
   - 接受本周未达成，下周继续

4. **记录每一笔交易**
   - 记录买入理由
   - 记录卖出原因
   - 总结经验教训

## 📉 常见错误

### 错误1：持仓过周末

**错误行为**：
- 周五没时间平仓
- 心理上不舍得平仓
- 期待周末利好

**后果**：
- 周末黑天鹅事件
- 周一大幅低开
- 止损被击穿

**正确做法**：
- 周五下午2点开始准备平仓
- 3点前所有持仓必须清空
- 周末好好休息

### 错误2：不严格止损

**错误行为**：
- 觉得只是暂时的
- 期待反弹再卖
- 移动止损线

**后果**：
- 小亏变大亏
- 3%止损变成10%亏损
- 严重影响心态

**正确做法**：
- 触发止损立即平仓
- 不要犹豫
- 不要移动止损线

### 错误3：过度交易

**错误行为**：
- 每天都想交易
- 持仓达到上限
- 频繁换仓

**后果**：
- 交易成本增加
- 心态变得急躁
- 容易犯错

**正确做法**：
- 等待好机会
- 每周2-3笔高质量交易
- 不交易也是一种交易

## 🎓 进阶话题

### 1. 动态仓位管理

根据市场状态调整仓位：
- 强势市场：满仓5只
- 震荡市场：3只仓位
- 弱势市场：1-2只仓位或空仓

### 2. 波动率调整止损

根据ATR调整止损：
- 高波动率：放宽止损至5%
- 低波动率：收窄止损至2%

### 3. 相关性管理

避免同时持有高度相关的股票：
- 不同时持有多只科技股
- 分散行业
- 股票+期货组合

### 4. 每周复盘

周末复盘要点：
- 本周盈利/亏损情况
- 哪些做对了
- 哪些做错了
- 下周改进计划
