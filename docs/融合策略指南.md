# 融合策略指南：期货+股票周波段交易系统

## 📊 策略概述

融合策略将**远期期货合约交易策略**和**周波段T0-T5短线策略**的优势完美结合，形成一个统一的交易系统。

---

## 🎯 核心理念

### 为什么需要融合？

**股票策略的优势**：
- ✅ 长期看好标的，基本面扎实
- ✅ 可以反复做波段，提高收益
- ✅ 流动性好，容易进出

**期货策略的优势**：
- ✅ 远期合约波动更大，收益潜力高
- ✅ 可以双向交易（做多/做空）
- ✅ 情绪驱动，灵活应对市场

**融合后的优势**：
- ✅ **多策略协同**：股票+期货，分散风险
- ✅ **统一规则**：T0-T5周期，不过周末
- ✅ **情绪驱动**：每日根据市场情绪选择方向
- ✅ **严格风控**：股票止损3%，期货风险度<50%
- ✅ **明确目标**：每周净赚2万（2%）

## 🔄 交易流程

### 每日操作流程

```
┌─────────────────────────────────────────────────────────────┐
│                    每日交易流程                              │
└─────────────────────────────────────────────────────────────┘

1. 【扫描机会】
   ├─ 扫描股票机会（长期看好标的）
   │  ├─ 计算技术指标（MA、RSI、波动率）
   │  ├─ 评估信号强度
   │  └─ 按分数排序
   │
   └─ 扫描期货机会（远期高波动合约）
      ├─ 筛选远期合约（+2个月以上）
      ├─ 对比波动率
      └─ 选择波动最高的

2. 【分析情绪】
   ├─ 统计上涨/下跌品种数
   ├─ 计算前20大涨幅/跌幅
   ├─ 判断市场倾向
   └─ 计算信心度

3. 【选择方向】
   ├─ 多头：上涨品种>60% 或 前20涨幅>前20跌幅
   ├─ 空头：上涨品种<40% 或 前20跌幅>前20涨幅
   └─ 中性：其他情况

4. 【开仓（信心度>0.65）】
   ├─ 股票：长期看好标的，回调时买入
   │  ├─ 计算持仓数量（风险2%）
   │  ├─ 设置止损3%、止盈6%
   │  └─ 最大持仓5天
   │
   └─ 期货：远期高波动合约
      ├─ 计算合约数量（风险度50%）
      ├─ 保证金<50%，预留1倍资金
      └─ 最大持仓5天

5. 【持仓管理】
   ├─ 每日检查止损止盈
   ├─ 达到目标立即平仓
   ├─ 触发止损立即平仓
   └─ 周五强制平仓

6. 【复盘总结】
   ├─ 计算本周盈亏
   ├─ 对比目标（2万）
   ├─ 分析胜率
   └─ 调整下周计划
```

```python
        # 2. 选择波动高于主力的
        higher_vol_contracts = [c for c in far_contracts
```

```python
# 风险度50%
available_margin = capital * 0.50
single_contract_margin = price * 0.15  # 15%保证金
contracts = int(available_margin / single_contract_margin)

# 预留资金 = 保证金（1倍）
margin_required = price * contracts * 0.15
reserve_capital = margin_required  # 1倍预留

# 风险度 = 保证金 / (保证金 + 预留)
risk_level = margin_required / (margin_required + reserve_capital)
# risk_level = 50% ✅
```

### 统一情绪分析

#### 分析逻辑

```python
def analyze_market_sentiment(market_data, current_date):
    # 1. 计算涨跌品种
    up_symbols = [c for c in daily_changes if c['change_pct'] > 0]
    down_symbols = [c for c in daily_changes if c['change_pct'] < 0]
    up_ratio = len(up_symbols) / total_symbols

    # 2. 计算前20大涨幅/跌幅
    top20_avg_gain = mean([c['change_pct'] for c in top20_gains])
    top20_avg_loss = mean([abs(c['change_pct']) for c in top20_losses])

    # 3. 判断情绪
    if up_ratio > 0.60:
        bias = 'long'
        confidence = 0.5 + (up_ratio - 0.60) * 2
    elif up_ratio < 0.40:
        bias = 'short'
        confidence = 0.5 + (0.40 - up_ratio) * 2

    if top20_avg_gain > top20_avg_loss:
        if bias == 'neutral':
            bias = 'long'
        elif bias == 'long':
            confidence += 0.2

    return MarketSentiment(bias, confidence)
```

|--------|------|
| > 0.65 | 开仓 |
| 0.50 - 0.65 | 观望 |
| < 0.50 | 不开仓 |

```python
from quant_trade_system.strategies import (
    HybridSwingStrategy,

# 1. 创建策略
strategy = HybridSwingStrategy(
    initial_capital=1_000_000,
    weekly_target=20_000,
    max_positions=5,
)

# 2. 扫描机会
stock_ops = strategy.scan_stock_opportunities(market_data, current_date)
futures_contracts = strategy.scan_futures_contracts(current_date)

# 3. 分析情绪
sentiment = strategy.analyze_market_sentiment(market_data, current_date)

# 4. 选择方向
side = strategy.select_position_side(sentiment)

# 5. 开仓
if sentiment.confidence > 0.65:
    # 股票
    if stock_ops:
        position = strategy.enter_stock_position(
            stock_ops[0], current_date, capital
        )

    # 期货
    if futures_contracts:
        position = strategy.enter_futures_position(
            futures_contracts[0], side, current_date, capital
        )

# 6. 平仓
should_exit, reason = strategy.should_exit_position(position, current_price)
if should_exit:
    strategy.exit_position(position, exit_date, exit_price, reason)
```

## 💡 实战技巧

### 选股技巧

1. **优先选择长期看好标的**
   - 美股科技龙头（AAPL、MSFT、GOOGL）
   - 港股科技（0700.HK、9988.HK）
   - 基本面扎实，波动适中

2. **等待回调买入**
   - RSI < 40：严重超卖
   - 30 < RSI < 50：超卖回升
   - 不要追高

3. **分批建仓**
   - 不要一次性满仓
   - 留有余地
   - 可以反复接回

### 选期货技巧

1. **优先选择波动大的品种**
   - 螺纹钢、铜、原油等
   - 波动率 > 主力合约5%以上

2. **关注流动性**
   - 成交量 > 1000手
   - 持仓量 > 5000手

3. **距离交割月>1个月**
   - 避免交割风险
   - 可以提前换月

### 开仓技巧

1. **情绪强烈才开仓**
   - 信心度 > 0.65
   - 两个条件都满足更好

2. **优先选择波动更大的**
   - 期货波动 > 股票
   - 收益潜力更大

3. **设置止损止盈**
   - 开仓后立即设置
   - 不要移动止损线

### 平仓技巧

1. **达到止盈及时平仓**
   - 不要贪婪
   - 落袋为安

2. **触发止损立即平仓**
   - 不要犹豫
   - 保护本金

3. **周五强制平仓**
   - 不过周末
   - 规避隔夜风险

## 📉 风险管理

### 股票风险控制

**单笔风险**：
- 每次交易风险<本金的2%
- 止损固定3%

**总仓位**：
- 单只股票<总资金的20%
- 总持仓<总资金的80%

### 期货风险控制

**单笔风险**：
- 保证金<总资金的50%
- 预留资金≥保证金（1倍）

**风险度**：
- 风险度 = 保证金 / (保证金 + 预留)
- 必须 < 50%

### 极端情况

**行情快速波动**：
- 立即平仓观望
- 等待市场明朗

**触发追加保证金**：
- 立即平仓
- 不要追加资金
