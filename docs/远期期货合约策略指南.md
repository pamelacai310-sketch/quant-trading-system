# 远期期货合约交易策略指南

## 📊 策略概述

远期期货合约交易策略是一种专注于**远期合约**、**严格资金管理**和**情绪驱动**的期货交易策略。

### 三大核心规则

1. **只做远期合约**：选择波动幅度高于主力合约的远期合约，至少+2个月
2. **严格资金管理**：期货仓位风险度<50%，预留资金≥保证金（1倍）
3. **情绪驱动方向**：每日根据市场多空情绪选择开仓方向

---

## 🎯 核心逻辑详解

### 1. 远期合约选择

#### 为什么选择远期合约？

**远期合约的优势**：
- **波动更大**：远期合约通常比主力合约波动更剧烈
- **趋势更明确**：远期合约受供需预期影响更大
- **杠杆效应**：同样的保证金可以获取更大的波动收益

**示例对比**：
```
螺纹钢合约（2026年5月）：
- 主力合约：RB2606（7月交割），波动率20%
- 远期合约：RB2610（10月交割），波动率25%
- 波动差异：25% - 20% = +5% ✅ 选择远期合约
```

#### 选择规则

**规则1：至少+2个月**
```
当前日期：2026年5月4日
主力合约：7月交割（+2个月）
可选合约：9月（+4个月）、10月（+5个月）
```

**规则2：波动率高于主力**
```
主力合约波动率：20%
远期合约A（9月）：23% ✅
远期合约B（10月）：22% ✅
选择：9月合约（波动率更高）
```

**规则3：在符合条件中选波动最大的**
```
主力：20%
9月：23%
10月：25%
11月：21%
选择：10月合约（波动最大）
```

### 2. 资金管理

#### 风险度控制

**核心公式**：
```
风险度 = 保证金 / (保证金 + 预留资金)

要求：风险度 < 50%
```

**示例计算**：
```
合约：螺纹钢
价格：4000元/吨
合约数：10手
保证金比例：15%

计算：
合约价值 = 4000 × 10 = 40,000元
保证金 = 40,000 × 15% = 6,000元
预留资金 = 6,000元（1倍保证金）
总资金 = 6,000 + 6,000 = 12,000元
风险度 = 6,000 / 12,000 = 50% ✅
```

#### 预留资金的重要性

**为什么需要1倍预留资金？**
- 期货价格波动剧烈，可能触发追加保证金
- 预留资金防止爆仓
- 保持策略可持续性

**示例**：
```
错误做法：
保证金10万，预留0万
价格波动5% → 可能爆仓 ❌

正确做法：
保证金10万，预留10万
价格波动5% → 仍有安全边际 ✅
```

### 3. 市场情绪驱动

#### 每日情绪分析

**规则1：上涨品种数量**
```
上涨品种数 / 总品种数 > 60% → 做多
上涨品种数 / 总品种数 < 40% → 做空
40% - 60%之间 → 中性
```

**规则2：极端品种对比**
```
前20大涨幅品种平均涨幅 > 前20大跌幅品种平均跌幅 → 做多
前20大跌幅品种平均跌幅 > 前20大涨幅品种平均涨幅 → 做多
```

**信心度评估**
```
两个条件都满足 → 信心度0.9（强烈信号）
只满足一个条件 → 信心度0.7（中等信号）
都不满足 → 信心度0.5（弱信号，不开仓）
```

## 📈 实战应用

### 完整交易流程

#### 每日操作步骤

**步骤1：扫描远期合约**
```python
# 扫描所有标的物
suitable_contracts = strategy.scan_contracts(current_date)

# 筛选条件：
# 1. 至少+2个月
# 2. 波动率 > 主力合约
```

**步骤2：分析市场情绪**
```python
# 获取市场数据
market_data = get_market_data()

# 分析情绪
sentiment = strategy.analyze_market_sentiment(market_data, current_date)

# 判断方向
if sentiment.confidence > 0.65:
    side = select_position_side(sentiment)
```

**步骤3：开仓**
```python
# 计算合约数量
contracts = calculate_position_size(contract, capital)

# 计算保证金和预留资金
margin, reserve = calculate_margin_requirement(contract, contracts)

# 检查风险度
risk_level = margin / (margin + reserve)
assert risk_level < 0.50  # 必须小于50%
```

**步骤4：持仓管理**
```python
# 每日检查
should_exit, reason = should_exit_position(position, current_price)

if should_exit:
    exit_position(position, current_date, current_price, reason)
```

### 示例交易

#### 案例1：做多螺纹钢远期合约

**市场环境**（2026年5月4日）：
- 上涨品种：18/30 = 60%
- 前20涨幅平均：+4.5%
- 前20跌幅平均：-2.3%
- 市场情绪：多头，信心度0.75

**合约选择**：
- 标的：螺纹钢（RB）
- 主力：RB2606（7月），波动率22%
- 远期：RB2610（10月），波动率27%
- 选择：RB2610 ✅（波动率高5%）

**开仓**：
```python
合约：RB2610
方向：做多
当前价：4000元/吨
合约数：10手
保证金：4000 × 10 × 15% = 6,000元
预留：6,000元
风险度：50% ✅
止损：-3%（3880元/吨）
止盈：+6%（4240元/吨）
```

**持仓管理**：
- T1：价格3950，亏损-1.25%，继续持有
- T2：价格4080，盈利+2%，继续持有
- T3：价格4240，触发止盈+6%，平仓

**结果**：
- 盈利：(4240 - 4000) × 10 = +2,400元
- 收益率：2,400 / 6,000 = +40%
- 持仓天数：3天

## 💡 实战技巧

### 选合约技巧

1. **优先选择波动大的品种**
   - 螺纹钢、铜、原油等波动大
   - 避免波动太小的品种

2. **关注品种基本面**
   - 供应紧张/过剩
   - 需求旺盛/疲软
   - 政策影响

3. **流动性检查**
   - 成交量>1000手
   - 持仓量>5000手

### 开仓技巧

1. **情绪强烈才开仓**
   - 信心度>0.65
   - 两个条件都满足更好

2. **分批建仓**
   - 不要一次性满仓
   - 留有余地

3. **设置止损**
   - 开仓后立即设置止损单
   - 不要移动止损线

### 平仓技巧

1. **达到止盈及时平仓**
   - 不要贪婪
   - 落袋为安

2. **触发止损立即平仓**
   - 不要犹豫
   - 保护本金

3. **临近交割月提前平仓**
   - 避免交割风险
   - 换到更远的合约

## 📉 风险管理

### 仓位管理

**单品种风险**：
- 单个品种保证金<总资金的20%
- 单个品种预留资金≥保证金

**总仓位风险**：
- 所有品种保证金总和<总资金的50%
- 预留资金总和≥保证金总和

### 止损止盈

**止损**：
- 硬止损：-3%
- 不移动止损线
- 触发立即平仓

**止盈**：
- 目标止盈：+6%
- 可以分批止盈
- 达到目标立即平仓

### 极端情况

**行情快速波动**：
- 立即平仓观望
- 等待市场明朗

**触发追加保证金**：
- 立即平仓
- 不要追加资金
